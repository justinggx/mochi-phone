# MochiPhone 小店云存档服务

小店的主存档需要同一酒馆服务器上的配套服务。前端不会在服务缺失时降级成浏览器主存档。

本版已验证 Node 22.22.2 的内置 `node:sqlite`，没有新增 npm 依赖。需要酒馆启用 `enableServerPlugins`，并使用酒馆账户登录。安装入口文件 `plugins/mochi-shop/index.mjs`：

```js
export {info, init, exit} from '../../public/scripts/extensions/third-party/mochi-phone/server/index.mjs';
```

服务端插件加载需要计划内重启酒馆；前端扩展更新本身不安装服务器文件。托管云酒馆需由管理员提供该服务。

每个账户私有目录下的 `mochi-shop/shop.sqlite` 为主档，SQLite WAL/完整同步事务、递增版本、操作编号去重及设备经营权防止旧设备覆盖。酒馆数据目录须位于持久磁盘/持久卷。所有主档和自动备份属于用户所在酒馆的个人账户，不上传到插件作者或其他统一存储。店铺ID独立于主楼聊天，角色资料为创建时所选卡片及其绑定世界书快照；不会读取当前主楼历史。世界书轻量匹配支持常驻、文字关键词及副关键词逻辑，不运行正则、递归宏或完整宿主世界书脚本。

每个经营操作收到服务器确认才生效；不确认时保留操作编号并核对，不盲目重做。角色生成失败不撤销已确认经营，不自动改钱或库存；失败回复需要手动重试。

自动保留每档最近30个重要节点，手动点最多500个，原档可移入回收区再恢复。旧点接续和导入都会创建独立新档，不与现有钱/库存相加。导出文件保存完整当前进度、当前档全部账本/回忆/对话和所选人物快照；历史存档点留服务器，需要时从旧点另建档再导出。

数据库私有备份在 `mochi-shop/backups/`，有活动账户缓存时每15分钟至多一次，服务退出也尝试备份；用SQLite一致性副本落盘后改名。保留最近96份并补每天一份、最多30个有备份的日期，总量上限约512MiB（至少保留最新两份）。服务未运行或账户从未访问时没有定时器。主档事务仍每次操作保存，自动备份异常不会冒充备份成功。

单账户主库上限约256MiB、最多100份未回收档案，单档当前状态最多6,000,000 UTF-8字节；到达限额会明确拒绝新写入并保留原档，不截断历史。请导出、保留完整服务器目录并联系维护者处理容量。API密钥不在游戏存档中。下载文件包含人物资料和店内对话，应私有保管。

数据库备份恢复：停用小店写入并备份整个当前 `mochi-shop/` 目录；在独立目录校验选定SQLite副本后，再由管理员安排恢复，避免把旧WAL/SHM与新主库混用。不会因切换前端版本删除数据库。用户自行点击导出，将文件保存到自己的设备或个人网盘；本版没有要求统一备份目的地，也不提供自动向第三方网盘上传。同盘备份不能应对整台服务器/磁盘丢失，设备端副本需用户实际下载保管。
